# プロンプト集

サイトのオーナーが Claude に送る文章です。（ ）の部分を書き換えて使います。

## はじめるとき

```
GitHub の tkc310/ai-web-creator にあるスキル（skills フォルダ）を読み込んで、
私のサイト作りを手伝ってください。
私は IT に詳しくありません。
質問は選択肢をつけて、一度に5つまでにしてください。
```

## Claude Code に移ってから最初に送る文章

チャットでの相談の最後に、Claude が引き継ぎ文を作ります。それをそのまま送ります。引き継ぎ文がない場合は、次の文章を使います。

```
GitHub の tkc310/ai-web-creator にあるスキル（skills フォルダ）に従って、
（サイトのリポジトリ名）にサイトを作ってください。
チャットで相談した内容は次のとおりです。
（相談の内容を貼る）
```

## 今のサイトから引っ越すとき

```
今のサイト（URL）から引っ越したいです。今のサイトは（WordPress などの CMS / ノーコードのサービス）で作っています。
検索順位や問い合わせが減らないように進めてください。
```

## デザインを選ぶとき

```
（B）の案で進めてください。（色は A のほうが好きです。）
```

## 要点だけ伝えて記事にしてもらうとき

```
お知らせを書いて公開してください。要点は次のとおりです。
・（年末年始は 12/29〜1/3 まで休業）
・（1/4 から通常営業）
・（休業中のお問い合わせは 1/4 以降に順番に返信）
公開する前に、スマホで見たときの画面を見せてください。
```

## 書いた文章を校正して載せてもらうとき

```
この文章を校正して、ブログに載せてください。直したところは一覧で教えてください。
（文章を貼る）
```

## 記事やお知らせを追加するとき

```
この Google ドキュメントの内容を、お知らせに載せてください。
公開する前に、スマホで見たときの画面を見せてください。
（ドキュメントのリンク）
```

## 直してほしいとき

```
（会社概要の住所）を（〇〇ビル3階）に直してください。
```

## 公開に失敗したとき

```
GitHub から公開失敗のお知らせが来ました。直して、原因を教えてください。
```

## わからないことがあるとき

```
（このサイトにかかっている費用）を、わかりやすく教えてください。
```

## 別の会話で続きを頼むとき

```
（サイト名）のホームページの続きをお願いします。
GitHub の（リポジトリ名）にある SITE.md を最初に読んでから進めてください。
```
