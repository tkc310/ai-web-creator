このサイトは、数百〜数千本の記事を持つメディアを想定したサンプルです。

## しくみ

記事は Markdown で書き、公開のときに JSON に変換します。ページの HTML は事前には作らず、アクセスがあったときに Worker が JSON から組み立てます。組み立てた HTML はキャッシュされるので、2回目からは Worker が動きません。
