# Cursor や ChatGPT で使う

このリポジトリのスキルは、Claude 以外のエージェントでも使えます。スキルは SKILL.md という共通の形式（Agent Skills）で書いているため、Cursor や ChatGPT（Codex）でも読み込めます。

ただし、このリポジトリは Claude で使うことを前提に作っています。Claude にしかない機能を使う部分は、ほかのエージェントでは手作業に置き換わります。作業の進み方や仕上がりも、Claude で使う場合より劣る可能性があります。

## スキルの置き場所

スキルの本体は `skills/` にあります。各エージェントが探す場所から、`skills/` へのリンクを置いています。

| エージェント | 読み込む場所 |
|---|---|
| Claude Code | `.claude/skills/` |
| Cursor | `.agents/skills/`、`.cursor/skills/`、`.claude/skills/` |
| ChatGPT（デスクトップアプリ）・Codex | `.agents/skills/` |

Windows でリンク（シンボリックリンク）がうまく働かない場合は、`skills/` の中の各フォルダを、使うエージェントの場所（例: `.agents/skills/`）にコピーしてください。

## Cursor で使う

1. このリポジトリと、サイトのリポジトリを手元に用意する（Cursor でサイトのリポジトリを開く）
2. スキルを読み込ませる。次のどちらかで行う
   - このリポジトリの `skills/` の中の各フォルダを、サイトのリポジトリの `.agents/skills/` にコピーする
   - すべてのプロジェクトで使う場合は、`~/.cursor/skills/` にコピーする
3. Agent のチャットで `/` を入力して web-creator を選ぶか、「サイト作りを手伝ってください」と頼む

## ChatGPT（デスクトップアプリ）・Codex で使う

1. スキルのフォルダを `~/.agents/skills/` にコピーする（サイトのリポジトリだけで使う場合は、そのリポジトリの `.agents/skills/`）
2. ChatGPT のデスクトップアプリのサイドバーの「Skills」で、スキルが読み込まれていることを確認する
3. 「サイト作りを手伝ってください」と頼む

スキルの追加方法は変わることがあります。うまくいかない場合は、各サービスのスキルのドキュメントを確認してください。

## Claude にしかない機能の置き換え

| 機能 | Claude での動き | ほかのエージェントでの代わり |
|---|---|---|
| 公開前のプレビュー | アーティファクトで HTML のページを見せる | `make_preview.py --standalone` で作った HTML ファイルを渡し、ブラウザで開いて確認してもらう |
| 2週間ごとの保守 | スケジュールタスクで自動で動く | 自動で定期実行する機能がない場合は、毎月1日と15日に、オーナーが「保守して」と頼む。カレンダーのリマインダーを設定しておく |
| 公開の失敗の自動修正 | GitHub Actions で Claude が直す（autofix.yml） | Claude の鍵がない場合は autofix.yml を置かず、失敗の通知が来たらオーナーが「直して」と頼む |
| サービスの操作（コネクタ） | Claude のコネクタで Cloudflare や Google のサービスを操作する | Cloudflare の MCP サーバー（`https://mcp.cloudflare.com/mcp`）は、Cursor や Codex の MCP の設定にも追加できる。Google のサービスは、それぞれのエージェントの連携機能があれば使い、なければブラウザ操作か手順の案内にする |
| ブラウザの操作 | Claude in Chrome などで画面を進める | エージェントにブラウザの操作機能がなければ、画面ごとの手順を案内してオーナーが操作する |
| サイトごとのプロジェクト | プロジェクトの指示に、オーナーの環境と作業の決まりを書き、どの会話でも読ませる | プロジェクトの指示の内容を SITE.md の「作業の環境」に書き、毎回「SITE.md を最初に読んで」と頼む。Cursor のルールや AGENTS.md に書いてもよい |
| 月1回の振り返り | スケジュールタスクで site-review を動かす | 毎月1日に、オーナーが「振り返って」と頼む。カレンダーのリマインダーを設定しておく |
| 使うモデルと考える深さ | スキルの frontmatter（`model`、`effort`）で指定 | ほかのエージェントでは frontmatter の指定は使われないので、計画とデザインには推論の強いモデルを、構築には標準のモデルを、オーナーかエージェントが選ぶ |

## 注意

- スキルの中の「Artifact ツールで公開する」「スケジュールタスクを作る」といった手順は、その機能がないエージェントでは、上の表の代わりの手順に読み替えます（スキルの中にも、使えない場合の代わりを書いています）
- AGENTS.md は、多くのエージェントが読む共通の指示ファイルです。サイトのリポジトリの AGENTS.md に、エージェントへの指示を書いています
