# スキルとプロンプトの使い方

このリポジトリのスキルを Claude に読ませて、サイトを作り、公開し、運用するまでの使い方です。Claude のアカウントがまだない場合は、先に [Claude のアカウント登録ガイド](claude-account.md) を済ませてください。

## 全体の流れ

作業する場所は2つあります。

| 段階 | 作業する場所 | やること |
|---|---|---|
| 1. 相談と準備 | Claude のチャット（claude.ai、デスクトップアプリ、スマートフォンのアプリ） | 要望のヒアリング、作り方の決定、GitHub と Cloudflare のアカウント作成 |
| 2. 制作と運用 | Claude Code（claude.ai/code、デスクトップアプリの「Code」） | サイトの制作、公開、更新、保守 |

Claude Code はクラウド上の作業環境で動き、GitHub のリポジトリに直接保存します。そのため、GitHub のアカウントができてから使います。段階1から2に移るときは、Claude が移り方と、最初に送る文章を案内します。

## 段階1: チャットで相談する

Claude のチャットで、次の文章を送ります。

```
GitHub の tkc310/ai-web-creator にあるスキル（skills フォルダ）を読み込んで、
私のサイト作りを手伝ってください。
私は IT に詳しくありません。
質問は選択肢をつけて、一度に5つまでにしてください。
```

Claude が選択肢つきの質問をするので、答えていきます。ロゴ、写真、会社案内の PDF があれば、このときに添付します。

続いて、GitHub と Cloudflare のアカウントを作ります。

- 登録や設定の方法は、Claude が画面ごとに対話しながら教えます。分からない画面が出たら、スクリーンショットを貼って聞けます
- Claude にブラウザの操作を任せられる環境（Claude in Chrome、デスクトップアプリ）では、Claude が画面を進めます
- パスワードの入力、2段階認証、支払いと規約への同意、秘密の鍵の貼り付けは、必ずあなたが行います

相談の最後に、Claude が「Claude Code に移ってから最初に送る文章」を作ります。要望や決めたことがまとめて書かれているので、そのまま使います。

## 段階2: Claude Code で作る

1. GitHub に、サイト用の空の非公開リポジトリを作る（作り方は Claude が案内します）
2. Claude の GitHub アプリを、そのリポジトリにインストールする（[アカウント登録ガイド](claude-account.md) の「4. GitHub とつなぐ」）
3. claude.ai/code を開き、リポジトリの選択で「サイトのリポジトリ」と「tkc310/ai-web-creator」の2つを選ぶ
4. 段階1の最後に Claude が作った文章を送る

あとは、Claude がデザインの案を見せる、公開前のチェック結果を伝える、取り消しにくい操作の前に確認する、といった場面で返事をするだけです。

## 公開したあと

サイトの更新や質問は、Claude Code でサイトのリポジトリを選んで頼みます。毎回、最初に次の一文を入れると確実です。

```
（サイト名）のサイトの作業です。SITE.md を最初に読んでから進めてください。
```

頼み方の例は [プロンプト集](../prompts/README.md) にあります。

- お知らせやブログの追加: 原稿をチャットに書くか、Google ドキュメントのリンクを貼る
- 文章や写真の修正: 「ここをこう直して」と頼む
- 脆弱性のニュースを見かけたとき: 記事のリンクを貼って「このサイトに関係あるか確認して」と頼む

## 定期的な保守

一部のページをその場で処理する構成や、EmDash を使う構成の場合は、公開時に Claude がスケジュールタスク（旧称: ルーティン）を設定します。毎月1日と15日に、部品の更新を確認して反映します。設定の内容は [site-maintenance](../skills/site-maintenance/SKILL.md) にあります。

## スキルを Claude に登録して使う（任意）

上の方法では、毎回 GitHub のスキルを読み込ませます。よく使う場合は、スキルを Claude に登録しておくこともできます。

1. このリポジトリの skills/ の中から、使うスキルのフォルダ（例: web-creator）を、フォルダごと ZIP にする
2. claude.ai の「Customize」→「Skills」で「+」→「Create skill」→「Upload a skill」を選び、ZIP をアップロードする
3. アップロードしたスキルをオンにする

スキルを使うには、設定の「Capabilities」で「Code execution and file creation」がオンになっている必要があります。スキルを更新したときは、もう一度アップロードします。
