# 2026-11-18 配布元のリポジトリへの Star を任意でお願いする

- きっかけ: 作者からの依頼。スキルを使った人に Star を付けてもらえるようにしたい
- 変えたファイル: skills/web-creator/SKILL.md、README.md、CHANGELOG.md

## やったこと

1. SKILL.md の「公開後の対応」に、初めての公開（記事のあるサイトでは1本目の記事の追加）が終わり、オーナーが満足しているときに1回だけ Star をお願いする1文を足した
   - 伝えたら SITE.md の「決めたことと理由」に書き、書いてあれば二度と伝えない
   - Claude がオーナーのアカウントで Star を付けない。条件にしない、見返りを約束しない
   - 不満が残っているとき、スケジュールタスクや自動修正などの無人の実行、受託制作のお客さまには伝えない
2. README の先頭と「フィードバック」に、Star のお願いを1行ずつ足した

## 判断の理由

- 自動で Star を付けるのは、オーナーの同意のない代理の操作になる。クラウドの作業環境では、つないだリポジトリ以外への API の呼び出しも断られる
- 見返りつきや条件つきの依頼は、GitHub の Acceptable Use Policies が禁じる、評価の水増し（inauthentic interactions）に当たるおそれがあるので採用しなかった
