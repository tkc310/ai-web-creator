# 2026-11-18 README をオープンソースのリポジトリのような構成にする

- きっかけ: 作者からの依頼。README にバッジを付け、初めて見た人が全体をつかみやすい、よくあるリポジトリの形に整えたい
- 変えたファイル: README.md、CHANGELOG.md

## やったこと

1. 先頭に、題名、ひと言の説明、バッジ、ページ内の案内を置いた
   - 状態のバッジは、実際にあるものだけにした: check-skills のワークフロー、リリース（v2026.11.0）、最後のコミット、Issue の件数
   - ライセンスは GitHub が判定できない独自の条件（NOASSERTION）なので、動的なバッジではなく「proprietary」の固定のバッジにし、LICENSE へつないだ
   - 技術のバッジ（Claude、Astro、Cloudflare Workers、GitHub Actions）と、言語のバッジ（日本語）を足した
2. オープンソースではないことの注意を、GitHub の注記（`[!IMPORTANT]`）にした
3. 「特徴」を足し、設計の方針の要点を7行にまとめた
4. 見出しを並べ替えた: 特徴 → クイックスタート（旧「使い方」）→ 必要なもの → 対応しないもの → ドキュメント（旧「はじめての方へ」）→ 使うモデル → 中身 → スキルの構成 → 設計の方針 → 注意 → コントリビュート → フィードバック → ライセンス → 版の付け方（作者向け）
   - 「版の付け方（作者向け）」は、AGENTS.md、check-skills.yml、check_skills.py、versions.md などが見出しの名前で参照しているので、名前を変えずに最後へ移した
5. 「コントリビュート」を足した。ライセンスの都合でプルリクエストでのコードの持ち込みは受け付けず、Issue と note の窓口で受けることを書いた
