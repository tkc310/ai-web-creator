# お問い合わせフォームの作り方

サイトにお問い合わせフォームを置く方法と、それぞれの導入のしかたです。どの方法も、Claude に「お問い合わせフォームを付けたい」と頼めば、選ぶところから案内します。エージェント向けの詳しい手順は [skills/web-creator/references/forms.md](../skills/web-creator/references/forms.md) にあります。

## どれを選ぶか

| 方法 | あなたの手間 | 見た目 | 費用 | こんな人に |
|---|---|---|---|---|
| A. Google フォームをリンクで開く | 10分 | Google の見た目 | 無料 | まずはこれ。迷ったらこれ |
| B. Google フォームをお問い合わせページに埋め込む | 10分 | サイトの中に Google のフォームが入る | 無料 | サイトから離れずに送ってほしい |
| C. サイトと同じ見た目のフォーム（Cloudflare Email Sending） | 30〜60分。Claude と対話しながら進める | サイトと同じ | 無料の場合と、月5ドルの場合がある | 見た目にこだわりたい |
| D. フォームを置かない | なし | - | 無料 | 問い合わせはメールか電話で十分 |

A と B は、届いた問い合わせを Google スプレッドシートで一覧にでき、担当者で手分けするのにも向いています。C は届いたメールで受け取るだけで、送信内容はどこにも保存しません。

## A. Google フォームをリンクで開く

所要時間は10分くらいです。

1. Claude が、フォームに入れる項目（お名前、メールアドレス、お問い合わせ内容など）を提案します
2. Google アカウントで Google フォームを作ります。Claude にブラウザを操作できる環境（Claude in Chrome、デスクトップアプリ）なら、Claude が作ります。会社の共有の Google アカウントがあれば、そちらで作ると担当者が変わっても引き継げます
3. 「回答」タブで、新しい回答のメール通知をオンにし、回答をスプレッドシートにも書き出す設定にします（Claude が案内します）
4. 「送信」ボタンからリンクをコピーして、Claude に渡します
5. Claude がサイトのお問い合わせボタンをそのリンクにつなぎます
6. テストで1件送って、通知メールが届くことを確かめます

届いた問い合わせは、通知メールから Google フォームの「回答」タブか、スプレッドシートを開いて見ます。

## B. Google フォームをお問い合わせページに埋め込む

A の手順4で、リンクの代わりに「<>」（埋め込み）の HTML をコピーして Claude に渡します。あとは同じです。

埋め込むと、お問い合わせページの表示が少し遅くなります。Claude は、お問い合わせページにだけ埋め込み、ほかのページが遅くならないようにします。

## C. サイトと同じ見た目のフォーム（Cloudflare Email Sending）

サイトのデザインに合わせたフォームを Claude が作り、送信された内容を Cloudflare の機能であなたにメールで届けます。サイトの公開に使っている Cloudflare だけで完結し、ほかの会社に問い合わせの内容を預けません。

ただし、A や B よりも導入が難しく、次の点を了承したうえで選んでください。

- 手順が多い。Cloudflare の設定画面での確認、秘密の鍵の貼り付け、メールアドレスの確認など、あなたの操作が何度か入ります。Claude が画面ごとに案内します
- メールを送る機能（Email Sending）は、執筆時点で Cloudflare のベータ版です。画面や仕様が変わることがあります
- 料金は導入時に確かめます。自分宛ての通知だけなら無料とされていますが、無料のまま使えない場合は、Cloudflare の Workers の有料プラン（執筆時点で月5ドル）が必要です
- サイトがアクセスのたびに処理する部分を持つので、2週間ごとの自動保守（Claude のスケジュールタスク）を設定します。Claude の利用量を少し使います
- メールが届かないときの原因の切り分けは、あなた一人では難しくなります。そのときは Claude に「お問い合わせのメールが届かない」と頼んでください

### 導入の流れ

所要時間は、あなたの操作が30分くらいです。番号の頭に「あなた」とあるものだけ、あなたが操作します。

1. Claude: Cloudflare の Email Sending に、サイトのドメインを登録する画面を開く
2. あなた: 登録を確定する
3. Claude: 通知を受けるメールアドレスを、Cloudflare に登録する
4. あなた: 届いた確認メールのボタンを押す
5. Claude: ロボットの送信を防ぐ仕組み（Turnstile）を設定する
6. あなた: Turnstile の秘密の鍵をコピーして、Cloudflare の設定画面に貼る（Claude には渡しません）
7. Claude: フォームと、送信を受ける仕組みを作り、確認用の URL で公開する
8. あなた: テストで1件送り、メールが届くこと、そのメールに返信すると送信した人に届くことを確かめる（迷惑メールのフォルダも見る）
9. Claude: 本番に公開し、2週間ごとの自動保守を設定する

今お使いのメール（info@ など）は、そのまま使えます。

### 守っていること

- 送信元が自分のサイトかどうか、文字数、メールアドレスの形を、サーバーで確かめます
- ロボットの送信は、Turnstile と、人には見えない入力欄で防ぎます
- 送信された内容は、メールで届けるだけで、どこにも保存しません
- 送信した人への自動返信は付けません。必要な場合は、費用と注意点を Claude が説明します

## 番外編: ほかのサービス

フォームのサービスやメール送信のサービスは、ほかにもあります。使うこともできますが、問い合わせの内容（名前、メールアドレスなど）を預ける会社が、Google や Cloudflare とは別にもう1つ増えます。預け先が増えるほど流出の入り口が増えるので、このリポジトリでは標準にしていません。

| サービス | 種類 | 無料プランのおもな内容（執筆時点） | 注意すること |
|---|---|---|---|
| formrun | フォームの作成と管理（日本の会社） | 1フォーム、月30件まで。回答をカードで管理できる | 書き出しや外部連携は有料。自動返信は有料 |
| Tally | フォームの作成と管理 | フォームも回答も無制限（公正な利用の範囲）。Google スプレッドシートとの連携あり | データはヨーロッパに保存。Tally のロゴが出る |
| Web3Forms | 自分の HTML のフォームの送信先 | 月250件まで | 運営元の情報が少ない。保存についての説明が食い違っている。上限を超えると翌月まで受け付けが止まる |
| Formspree | 自分の HTML のフォームの送信先 | 月50件まで。30日分の一覧 | 無料プランはテスト向けの位置づけ |
| Resend | メール送信（C のメール送信の代わり） | 月3,000通、1日100通まで | アカウントと秘密の鍵が1つ増える。C と同じく自動保守が必要 |

使う場合は、Claude に「（サービス名）を使いたい」と伝えてください。運営元、データの保存場所と期間を確かめ、プライバシーポリシーへの記載とあわせて設定します。

## どの方法でも必要なこと

- サイトにプライバシーポリシーのページを置き、集める情報、使い道、処理を任せる会社と国（Google や Cloudflare は米国の会社）を書きます。ひな形は Claude が作りますが、正式な文面は専門家に確認してください
- フォームで、健康状態、口座番号、マイナンバーのような慎重に扱う情報は聞かないでください
- 不要になった問い合わせの記録は、定期的に削除してください（A・B は Google フォームとスプレッドシート、C はメール）
