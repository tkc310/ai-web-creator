## 更新の方法

- お知らせ: `src/content/news/` に Markdown を追加（site-content-update スキル）
- オーナーが原稿を置く場所: （例: Claude ドキュメント（指定がないときの既定）/ Googleドライブの「サイト原稿」フォルダ）
- 記事の追加チュートリアル: 未 / YYYY-MM-DD に実施 / あとで / 行わない（記事のないサイトは不要）
- 確認なしで公開してよい変更: （例: 誤字の修正）
  - ここに書いた種類でも、次の4つはプレビューを必ず見せる: 要点から作った下書き、数字（営業時間、価格、日付）の変更、ページの部品（.astro）の変更、人が写っている写真の追加や差し替え（references/preview.md）
- 原稿の校正: いつも校正してよい / 指示があるときだけ
