# <サイト名> のホームページ

このフォルダ（リポジトリ）には、<サイト名> のホームページの中身がすべて入っています。
中身を直接さわる必要はありません。変更や質問は、Claude に話しかけて頼んでください。

- 公開中のサイト: https://example.co.jp
- 最後に更新した日: YYYY-MM-DD

## 頼み方の例

- 「お知らせに、年末年始の休業日を追加して。12/29〜1/3 です」
- 「Googleドキュメントの『新サービス紹介』をブログに載せて」（ドキュメントのリンクを貼る）
- 「トップの写真を、添付した写真に差し替えて」
- 「今月どのくらい見られているか教えて」
- 「昨日の変更で表示がおかしくなったので、前の状態に戻して」

## 知らせが届く場所

- サイトの公開に失敗したときや、自動で直せなかったときは、GitHub の Issue「サイトの公開に失敗しました」ができ、GitHub に登録したメールアドレスに知らせが届きます
- 公開の段階や公開のあとの確認だけがうまくいかなかったときは、Issue「サイトの公開について確認してください」ができます。こちらはお知らせで、開いたままでも自動の修正は止まりません
- 自動の修正に使う Claude の鍵が受け付けられなかったときは、Issue「Claude が使えないため、自動修正が止まっています」ができます。Claude を無料のプランにしている月に出るお知らせで、開いたままでもかまいません（下の「Claude を無料のプランにしている月」）
- 定期の保守や振り返りで、あなたに確かめたいことがあるときは、ラベル「owner-check」の付いた Issue ができることがあります
- 失敗のメールが来ても、Claude が自動で直した場合は何もしなくてかまいません。直した内容は、次に話すときに Claude から伝えます
- 定期の保守や振り返りの結果は、Claude のスケジュールタスクの画面と、このリポジトリの logs/ に残ります

## Claude を無料のプランにしている月

更新しない月は、Claude を無料のプラン（Free）に下げられます。ただし、サイトと同じ見た目のお問い合わせフォームのように、その場で処理するページがあるサイトでは下げません。下げる前に、Claude に「来月から Claude を無料のプランに下げても大丈夫か確かめて」と頼んでください。

- 動き続けるもの: サイトの表示と、GitHub の画面で文章を直したときの公開
- 止まるもの: 定期の保守と振り返り、予約した記事の公開、自動の修正

### GitHub の画面で文章を直す

1. GitHub でこのリポジトリを開き、src/content/ の中の直したい記事のファイル（.md）を開く
2. 右上の鉛筆のボタン（Edit this file）を押す
3. 文章を直す。先頭の `---` で囲まれた部分（題名や日付）は、記号を消さないように気をつける
4. 右上の「Commit changes...」を押し、出てきた画面でもう一度「Commit changes」を押す
5. 5分ほど待って、公開中のサイトで直ったかを確かめる（GitHub の「Actions」のタブで、deploy に緑のチェックが付いていれば公開済み）

- 写真の差し替えと新しい記事の追加は、Pro に戻してから Claude に頼んでください。写真の位置情報を消す処理や、題名と日付の書き方の確かめを Claude が行うためです。急いで写真を外したいときは、記事のファイルで写真の行（`![` で始まる行）を消します
- 書き間違いで公開に失敗すると、Issue ができてメールが届きます。サイトは直す前の状態のまま表示されているので、慌てなくて大丈夫です。同じファイルをもう一度開いて直してください
- 公開されたあとで表示がおかしいときは、同じファイルを開いて元の文章に書き直します。元の文章は、ファイルの画面の「History」で、直す前の版を開くと見られます。いちばん確実なのは、Pro に戻して Claude に「表示がおかしいので、直前の変更を取り消して」と頼むことです

### Pro に戻した日

Claude を Pro に戻したら、Claude（サイトのプロジェクトの会話）に次のように送ってください。止まっていた自動の手入れを確かめ、保守と振り返りをまとめて1回行います。

```
Claude を Pro に戻しました。止まっていた間の確認と、保守と振り返りをまとめてしてください。
```

## もしものとき

- 「サイトの公開に失敗しました」か「サイトの公開について確認してください」というメールが来たら、Claude に「サイトの公開が失敗しているので、Issue を見て直して」と頼んでください
  - 公開の前の段階で失敗した場合は、直るまで、サイトは前の状態のまま表示されています
  - 公開のあとの確認で失敗した場合は、新しい状態で公開されています。表示がおかしければ、前の状態に戻すよう頼んでください
- パスワードや認証コードは、Claude にも誰にも送らないでください。
