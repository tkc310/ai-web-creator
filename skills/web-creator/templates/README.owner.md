# <サイト名> のホームページ

このフォルダ（リポジトリ）には、<サイト名> のホームページの中身がすべて入っています。
中身を直接さわる必要はありません。変更や質問は、Claude に話しかけて頼んでください。

- 公開中のサイト: https://example.co.jp
- 最後に更新した日: YYYY-MM-DD

## 頼み方の例

- 「お知らせに、年末年始の休業日を追加して。12/29〜1/3 です」
- 「Googleドキュメントの『新サービス紹介』をブログに載せて」（ドキュメントのリンクを貼る）
- 「トップの写真を、添付した写真に差し替えて」
- 「今月どのくらい見られているか教えて」
- 「昨日の変更で表示がおかしくなったので、前の状態に戻して」

## 知らせが届く場所

- サイトの公開に失敗したときや、自動で直せなかったときは、GitHub の Issue「サイトの公開に失敗しました」ができ、GitHub に登録したメールアドレスに知らせが届きます
- 公開の段階や公開のあとの確認だけがうまくいかなかったときは、Issue「サイトの公開について確認してください」ができます。こちらはお知らせで、開いたままでも自動の修正は止まりません
- 定期の保守や振り返りで、あなたに確かめたいことがあるときは、ラベル「owner-check」の付いた Issue ができることがあります
- 失敗のメールが来ても、Claude が自動で直した場合は何もしなくてかまいません。直した内容は、次に話すときに Claude から伝えます
- 定期の保守や振り返りの結果は、Claude のスケジュールタスクの画面と、このリポジトリの logs/ に残ります

## もしものとき

- 「サイトの公開に失敗しました」か「サイトの公開について確認してください」というメールが来たら、Claude に「サイトの公開が失敗しているので、Issue を見て直して」と頼んでください
  - 公開の前の段階で失敗した場合は、直るまで、サイトは前の状態のまま表示されています
  - 公開のあとの確認で失敗した場合は、新しい状態で公開されています。表示がおかしければ、前の状態に戻すよう頼んでください
- パスワードや認証コードは、Claude にも誰にも送らないでください。
