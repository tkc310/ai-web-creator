# AGENTS.md

このリポジトリは <サイト名> のウェブサイトです。オーナーは技術に詳しくありません。

1. 作業の前に SITE.md を読む
2. オーナーへの返事は、専門用語を避けて、次にすることを先に書く
3. 記事・お知らせの追加は site-content-update スキル、それ以外は web-creator スキルに従う
4. push の前に `npm run build`（package.json がある場合）を通す
5. 作業の終わりに logs/YYYY-MM-DD_内容.md を書き、必要なら SITE.md と README.md を更新する
6. パスワード、トークンなどの秘密情報は、どのファイルにも書かない
