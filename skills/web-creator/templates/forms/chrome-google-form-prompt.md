# Claude in Chrome のサイドパネルに貼る指示文（Google フォーム）

会話がオーナーのパソコンにつながっておらず、Claude がブラウザを操作できないときに使います（references/account-setup.md の「ブラウザ操作の準備（Claude in Chrome）」）。`<...>` を埋めてからオーナーに渡します。オーナーは Chrome の右上の Claude のマークからサイドパネルを開き、下のコードブロックの中身を貼って送ります。最後に表示されたリンクを、元の会話に貼ってもらいます。

受け取ったら、フォームを WebFetch で開き、題名、説明、質問と必須の設定が指示どおりかを確かめます。

```
Google フォームで、ホームページのお問い合わせフォームを作ってください。
ログイン画面やパスワード、2段階認証が出たら、操作を止めて私に交代してください。

1. forms.google.com を開き、「空白のフォーム」で新しいフォームを作る
2. 題名: お問い合わせ｜<サイト名>
   説明: ご入力いただいた内容は、お問い合わせへの返信にのみ使用します。<プライバシーポリシーがあれば、その URL>
3. 質問を次の順に作る
   - お名前（記述式・必須）
   - 会社名（記述式・任意）
   - メールアドレス（記述式・必須。回答の検証で「テキスト」→「メールアドレス」）
   - 電話番号（記述式・任意）
   - お問い合わせ内容（段落・必須）
4. 「設定」タブ →「プレゼンテーション」→「確認メッセージ」を
   「お問い合わせありがとうございます。<日数>営業日以内にご連絡します。」にする
5. 「回答」タブ → 右上の「︙」→「新しい回答についてのメール通知を受け取る」をオンにする
6. 「回答」タブ →「スプレッドシートにリンク」→「新しいスプレッドシートを作成」で作成する
7. フォームを公開し（「公開」または「送信」）、回答者は「リンクを知っている全員」にする
8. 回答用のリンク（https://docs.google.com/forms/d/e/…/viewform の形）をコピーし、最後にそのリンクだけを表示する
   <埋め込み（B）の場合は「送信」→「<>」の HTML も表示する>

ほかのフォームやファイルは変更・削除しないでください。
```

質問の項目は forms.md の「作る」の1に従って、サイトに合わせて増減します。健康、口座番号、マイナンバーのような慎重に扱う情報は聞きません。
