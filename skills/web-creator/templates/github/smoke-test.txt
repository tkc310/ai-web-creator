# 公開後の確認（deploy と autofix のワークフローが読む）。サイトのリポジトリの .github/smoke-test.txt に置く。
# 1行に1つ、「URL」と「そのページに必ず含まれる文字」を空白で区切って書く。文字には空白を含めてよい。
# 文字は、ページの種類ごとに、表示が崩れても残る固有の言葉（サイト名、見出しなど）を選ぶ。
# 文字はページの HTML の中で探す。& は &amp; と書くか、記号を含まない言葉を選ぶ。
# <...> が残っている行は確かめずに飛ばす（警告が出る）。push の前に <...> を埋める。
# workers.dev のサブドメインは、Cloudflare の Workers & Pages の画面か、コネクタで確かめる（account-setup.md）。
# 独自ドメインにつなぐときは、wrangler.jsonc に独自ドメインを書くのと同じコミットで、URL を本番のドメインに直す。
