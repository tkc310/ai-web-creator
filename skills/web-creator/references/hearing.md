# ヒアリング

サイトの目的と運用の仕方を、オーナーが選ぶだけで答えられる形で聞きます。聞いた内容は `SITE.md` の「概要」に書き残します。

## 1回目（必須・5問）

| # | 質問 | 選択肢の例 | 何に使うか |
|---|---|---|---|
| 1 | サイトで一番してほしいことは？ | 問い合わせ / 来店・予約 / 採用応募 / 商品やサービスを知ってもらう / 記事を読んでもらう | トップページの構成と、目立たせるボタン |
| 2 | 見てほしい人は？ | 取引先の担当者 / 近所のお客さん / 求職者 / 自由記述 | 文章の口調、デザインの方向 |
| 3 | 必要なページは？（複数選択） | トップ / 会社概要 / サービス / お知らせ / ブログ / 採用 / お問い合わせ / 会員だけが見られるページ / 記事へのコメント欄 / 1ページで十分 | 技術の選定（会員やコメントが必要かは stack-selection.md の Q2）、ページ構成 |
| 4 | 公開後、どのくらい更新しますか？ | ほぼしない / 月に数回 / 週に数回以上 / 毎日、複数人で | 更新の頼み方の説明（更新が多くても、それだけでは技術を変えない） |
| 5 | 今サイトはありますか？ | ない / CMS（WordPress など）/ ノーコードのサイト作成サービス / その他 | 引っ越しの有無（migration.md） |

## 2回目（1回目の答えを見て必要なものだけ）

- 雰囲気: 参考にしたいサイトのURL、または「信頼感」「親しみ」「高級感」「にぎやか」から選ぶ
- 素材: ロゴ、写真、会社案内のPDF、パンフレットがあれば添付してもらう。なければ「写真なしでも成り立つデザインにする」と伝える
- ドメイン: 持っているか（example.co.jp など）。持っていなければ取得は後で一緒にやると伝える
- 問い合わせの受け方: Google フォームをリンクで開く（おすすめ）/ Google フォームをページに埋め込む / サイトと同じ見た目のフォーム（導入に手間がかかり、月5ドルかかる場合がある）/ フォームは置かず、メールアドレスか電話番号を載せる。選択肢の説明と、自前のフォームを選ぶ前に伝えることは forms.md
- 掲載してはいけない情報: 個人の住所、未発表の情報など

## 3回目: 作業の環境（段階1の終わり、プロジェクトを作る前）

プロジェクトの指示（templates/project-instructions.md）を埋めるために聞きます。選択肢をつけて、一度に5問までにします。

| # | 質問 | 選択肢の例 |
|---|---|---|
| 1 | ふだん使うパソコンは？ | Mac / Windows / パソコンは使わない |
| 2 | ふだん使うブラウザは？ | Chrome / Safari / Edge / わからない |
| 3 | 更新を頼むのは、主にどの端末から？ | パソコン / スマートフォン / 両方 |
| 4 | 原稿や写真は、どこに置くことが多い？ | チャットに添付 / Google ドライブ / Claude ドキュメント / その他 |
| 5 | 連絡がつきやすい時間は？ | 平日の日中 / 平日の夕方以降 / 土日 / いつでも |

Claude のデスクトップアプリや Claude in Chrome を入れているかは、質問せずに、使えるツールがあるかで確かめます。分からなければ「入れていない」として書き、入れると何が楽になるかを一文で伝えます。

## 対象外の要望が出たとき

ネットショップ、決済、予約システムの自作などが必要と分かったら、SKILL.md の「対応しないもの」に従い、その場で伝えます。サイトの残りの部分は進めてよいかを確認します。

会員機能やコメント機能は対象外にしません。stack-selection.md の Q2・Q3 に従い、外部のサービスで足りるかを確かめてから、足りなければ EmDash で作ります。

## 受託制作だと分かったとき

依頼者が制作会社やフリーランスで、顧客のサイトを作ると分かったら、2回目で「公開後の記事の投稿は、だれが、どの方法で行いますか？」を聞きます（選択肢: 顧客が Claude に頼む / 制作者が代わりに投稿する / 顧客が AI を使わずに管理画面から投稿する）。最後の答えのときだけ、stack-selection.md の「補足: 投稿は顧客が管理画面で行う受託制作」に従います。LICENSE の受託制作の条件（事前の許諾）も、このときに伝えます。

## 聞かないこと

- 使いたい技術、サーバー、CMS の名前（エージェントが決める）
- 予算の細目（Claude の利用料と、ドメイン代以外は基本的にかからない、と最初に伝える）

## 答えがあいまいなとき

- 「おまかせ」と言われたら、業種の一般的な構成で進め、最初のプレビューで確認してもらう
- 回答が止まったら、仮の内容で作り始め、プレビューに「仮」と分かる印を付けて見せる。文章や写真はあとから差し替えられることを伝える
