# アカウント準備

サイトを公開するには、GitHub と Cloudflare のアカウントが必要です。Claude のアカウント作成は別記事で案内しているため、ここでは扱いません。

## 基本方針

- アカウントはオーナー本人の名義で作ります。エージェントや制作者の名義で作ると、将来オーナーが自分で管理できなくなるためです。
- メールアドレスは、担当者が変わっても受け取れる会社の共有アドレス（info@ など）を勧めます。
- エージェントはブラウザ操作で画面を進めますが、次の4つはオーナーに交代します。
  1. パスワードの入力と登録の確定
  2. 2段階認証の設定とコード入力
  3. 支払い情報の入力、規約への同意
  4. APIトークンなど秘密の文字列のコピーと貼り付け
- 交代するときは「今この画面です。やることは2つです」と、画面の位置と操作を番号付きで伝えます。終わったら「できた」と返してもらいます。

## ブラウザ操作の手段

使える順に試します。

1. Claude in Chrome（オーナーの Chrome を操作。オーナーのログイン状態をそのまま使える）
2. Claude デスクトップアプリ内のブラウザ
3. コンピューター操作（スクリーンショットを見ながらクリック・入力）

どれも使えない場合は、画面ごとの手順を番号付きで示し、オーナーに操作してもらいます。

## 1. GitHub（設計図の保管庫）

所要時間: 10分くらい

1. エージェント: github.com/signup を開く
2. オーナー: メールアドレス、パスワード、ユーザー名を入力し、パズル認証と確認コードを入力する
3. エージェント: プランは Free のままにする（非公開リポジトリも無料で作れる）
4. オーナー: 2段階認証を設定する（Settings → Password and authentication。認証アプリを推奨）
5. エージェント: Claude から GitHub に接続する手順を案内する（Claude の設定画面で GitHub を連携し、サイト用のリポジトリへのアクセスを許可する）

## 2. Cloudflare（世界中に配る配送センター）

所要時間: 10〜20分くらい（ドメインを取る場合は追加で10分）

1. エージェント: dash.cloudflare.com/sign-up を開く
2. オーナー: メールアドレスとパスワードを入力し、届いたメールの確認リンクを開く
3. オーナー: 2段階認証を設定する
4. エージェント: プランは Free を選ぶ
5. ドメイン
   - 持っていない場合: 候補をエージェントが3つほど出し、空き状況を確認する。購入と支払いはオーナーが行う
     - .com などは Cloudflare Registrar で取得できる
     - .jp・.co.jp は Cloudflare Registrar では取得できない（2026年10月時点の確認）。お名前.com などの国内の登録業者で取得し、ネームサーバーを Cloudflare に向ける。取得前に Cloudflare の TLD の一覧で最新の対応状況を確認する
   - 持っている場合: 今の管理会社（お名前.com、Xserver など）は変えずに、ネームサーバーを Cloudflare に向ける手順を案内する。切り替えは公開直前に行う（deploy-and-autofix.md の「独自ドメインの接続」）
6. APIトークン（GitHub から公開するための鍵）
   - エージェント: My Profile → API Tokens → Create Token を開き、「Edit Cloudflare Workers」テンプレートを選ぶところまで進める
   - オーナー: 「Create Token」を押し、表示されたトークンをコピーする
   - エージェント: アカウントID（ダッシュボードの右側に表示される英数字）を読み取る。アカウントIDは秘密ではないので、エージェントが扱ってよい
7. GitHub に鍵を登録する
   - エージェント: サイトのリポジトリの Settings → Secrets and variables → Actions → New repository secret を開く
   - オーナー: 名前 `CLOUDFLARE_API_TOKEN` で、コピーしたトークンを貼り付けて保存する
   - エージェント: `CLOUDFLARE_ACCOUNT_ID` を同じ画面で登録する（値はアカウントID）

## 3. 自動修正用の Claude の鍵（任意・おすすめ）

デプロイ失敗時に自動で直すには、GitHub Actions から Claude を呼ぶための鍵が必要です。autofix.yml は GitHub が用意するトークン（GITHUB_TOKEN）でコミットするため、Claude の GitHub アプリのインストールは不要です。

1. エージェント: 鍵の発行方法を案内する（Pro / Max プランなら Claude Code の `claude setup-token` で発行する鍵、それ以外は Claude Console の API キー）
2. オーナー: 発行した鍵を、`CLAUDE_CODE_OAUTH_TOKEN`（API キーの場合は `ANTHROPIC_API_KEY`）として GitHub の Secrets に登録する

鍵の発行方法は変わることがあるため、案内の前に anthropics/claude-code-action の README で最新の手順を確認します。オーナーがこの設定を見送った場合も、サイトの公開には影響しません（失敗時に Issue で知らせるだけになります）。

## 終わったら

- SITE.md の「アカウント」に、サービス名、登録メールアドレスの種類（例: 共有アドレス）、2段階認証の有無だけを書く。パスワードやトークンは書かない
- 作業ログに、オーナーに交代した回数と、つまずいた画面を書く
