# 記事の原稿のひな形（Claude ドキュメント）

原稿の置き場所の指定がないときに、Claude ドキュメントに作る原稿のひな形です。ドキュメントの名前は「（サイト名）の記事: （仮のタイトル）」にします。公開したら、名前の先頭に「【公開済み】」を付けます。

```
# タイトル
（例: 年末年始の休業のお知らせ）

## 種類
お知らせ / ブログ（どちらかを残す）

## 公開日
（空欄なら公開する日）

## 本文
（箇条書きの要点だけでもかまいません。Claude が文章に整えます）

## 写真
（ここに写真を貼るか、チャットに添付してください。なくてもかまいません）
```

リンクを渡すときは、オーナーに次の3つを伝えます。

```
原稿のドキュメントを作りました。（リンク）
要点だけでも書いていただければ、文章は Claude が整えます。写真はドキュメントに貼るか、チャットに添付してください。
書けたら、チャットで「書けました」と送ってください。
```
